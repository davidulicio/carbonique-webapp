# Original Field Notes source archive

`index.html` retains the supplied self-contained scientific report as source
material. It is no longer served by the public report routes. Replacing it does
not change the live site or overwrite database records.

The live read-only report at `/fieldnotes/` reads current sites, visits and
caveats from the database. Use its **Download HTML** action for a current
self-contained snapshot suitable for sharing or GitHub Pages. Export again after
later changes. See [Public site](../../docs/PUBLIC_SITE.md).

Historical extraction/import tools are described in [Imports](../../docs/IMPORTS.md).
Review source imports deliberately; existing edited records are preserved.
Everything committed in this folder is repository-visible. Keep credentials and
private account/configuration files outside the checkout.
